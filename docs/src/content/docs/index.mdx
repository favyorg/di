## Install

```bash
npm install @favy/di
```

## Quick Start

```typescript
import { Module, type Live } from '@favy/di';

const Clock = Module()('Clock', () => ({
  now: () => new Date(),
}));
type ClockLive = Live<typeof Clock>;

const Greeting = Module<ClockLive>()('Greeting', ({ Clock }) => ({
  message: () => 'Hello at ' + Clock.now().toISOString(),
}));

console.log(Greeting({ Clock }).message());
```

`Live<typeof Clock>` adds the value produced by `Clock` to the dependency type. The top-level call supplies module implementations, and @favy/di resolves them through the graph.
